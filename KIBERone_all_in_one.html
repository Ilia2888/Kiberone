Импорт учеников из Word / Excel

Как вставить: откройте список в Word / Excel / Google-таблице, скопируйте его (Ctrl+C) и вставьте в поле ниже (Ctrl+V) — или загрузите файл .docx / .txt / .csv.
Одна строка = один ученик: ФИО · дата рождения (дд.мм.гггг) — колонки таблиц распознаются автоматически (Tab / «;» / «|» / 2+ пробела).
Заполняется автоматически: дата зачисления — сегодня · IP-адрес записывается сам. Группа не выставляется, статус не выставляется — группу назначите позже в профиле группы.
База данных · SQL-скрипты проекта
Веб-приложение (Supabase / PostgreSQL)
  1. Откройте Supabase Dashboard проекта и зайдите в SQL Editor → New query.
  2. Перейдите на вкладку «Supabase (PostgreSQL)», нажмите «Копировать схему Supabase», вставьте текст в редактор и нажмите Run. Скрипт идемпотентен: повторный запуск безопасен.
  3. В Dashboard → Authentication → Users → Add user создайте пользователя (e-mail + пароль от 6 символов) — без него вход не пройдёт (RLS пускает только вошедших).
  4. Откройте этот HTML-файл в браузере (нужен интернет — SDK Supabase грузится с CDN) и войдите под созданным пользователем.
SQL Server 2022 (не обязателен для веб-части — отдельная база AppDb)
  1. В SSMS под логином sysadmin скопируйте скрипт со вкладки «SQL Server (T-SQL)» и выполните целиком: создастся база AppDb (temporal + CDC + аудит + демо-данные) и задания SQL Server Agent.
  2. Требования: запущен SQL Server Agent; существуют папки D:\Backup и D:\Audit; перед реальным использованием замените e-mail оператора dba@company.local и демонстрационный пароль логина app_svc. Для писем настройте Database Mail.
